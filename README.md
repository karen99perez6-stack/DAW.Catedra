# Aesthetica - Sistema para Salón de Belleza y Citas

## ¿De qué trata el proyecto?
Aesthetica es una plataforma web creada para facilitar la reserva de citas y administración en un salón de belleza. El sistema permite a los clientes revisar el catálogo de servicios, agendar citas sin que se cruzen los horarios, realizar simulaciones de pagos con anticipo y ubicar la sucursal mediante un mapa interactivo. También cuenta con una sección administrativa para ver estadísticas básicas del negocio.

## Herramientas y tecnologías
* HTML5 y CSS3: Estructura semántica, diseño adaptable con Grid y Flexbox.
* JavaScript: Lógica del sistema e interacción con la interfaz.
* Leaflet.js y OpenStreetMap: Mapa interactivo con la ubicación de la sucursal.
* API de Stripe (Modo prueba): Simulación de pagos y reservas.
* Chart.js: Gráficas de control para la parte administrativa.
* LocalStorage: Guardado local de datos de citas y usuarios.

---

## Vistas desarrolladas
* Inicio y Catálogo de Servicios: Vista principal con la información del local y mapa.
* Sistema de Citas: Formulario para elegir fecha, hora y servicio.
* Módulo de Pago: Simulación para confirmar la cita y el anticipo.
* Panel Administrativo: Vista con métricas e indicadores principales.
